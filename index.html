▶ Instalación

¿Cómo se instala?

Elige tu sistema operativo y sigue los pasos. En serio, son muy pocos.

01
Descarga el instalador
Ve a Releases en GitHub y descarga el archivo para tu sistema operativo.
02
Ejecuta como administrador
Clic derecho en install.ps1 → "Ejecutar con PowerShell". Acepta si te pide permisos.
03
Espera que termine
El script instala Java, TLauncher y configura todo solo. Demora 2–5 minutos dependiendo de tu internet.
04
Abre TLauncher y juega
TLauncher abre automáticamente. Crea un usuario, elige la versión del servidor y entra al mundo.

▶ Preguntas frecuentes

¿Algo no funcionó?

Sí, es seguro. Windows Defender a veces marca scripts de PowerShell descargados como sospechosos sin analizarlos. Puedes revisar el código en GitHub antes de ejecutarlo. Para omitir la advertencia, clic derecho en el archivo → Propiedades → marca "Desbloquear" y acepta.
Es el Gatekeeper de macOS. Abre Terminal, ve a la carpeta donde descargaste el archivo y ejecuta chmod +x install.sh seguido de ./install.sh. Si igual bloquea, ve a Preferencias del Sistema → Privacidad y Seguridad → permite la app.
TLauncher es un launcher no oficial que permite jugar de forma gratuita. No está vinculado a Mojang/Microsoft. Úsalo bajo tu responsabilidad; si tienes una cuenta oficial, te recomendamos el launcher oficial de Minecraft.
El instalador verifica primero. Si ya tienes Java compatible instalado, salta ese paso y continúa con TLauncher. Si tu versión de Java es incompatible, instala la correcta sin borrar la tuya.
Abre TLauncher, ve a la sección "Multiplayer" y agrega el servidor manualmente con la IP de arriba. Si el problema persiste, comparte el archivo install-log.txt con nosotros por WhatsApp.
En TLauncher, ve a Configuración → JVM Arguments y ajusta -Xmx. Para juego fluido recomendamos 2–3 GB si tienes 8 GB de RAM en total. No asignes más del 50–60% de tu RAM total.
